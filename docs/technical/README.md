# Technical Documentation

This folder is the home for detailed LocalMesh engineering documentation. Use it for architecture notes, design details, operational runbooks, technical decisions, and reference material that should live longer than a single implementation phase.

## Folder Guide

- `architecture/` - System structure, package boundaries, data flow, and cross-cutting design.
- `design/` - Detailed feature or subsystem designs before or during implementation.
- `decisions/` - Architecture decision records and important trade-off notes.
- `operations/` - Build, release, debugging, test, and maintenance runbooks.
- `references/` - Protocol notes, external references, diagrams, glossary entries, and supporting material.

## Writing Guidelines

- Prefer one focused document per topic.
- Start filenames with a date when the document captures a point-in-time decision or design, for example `2026-05-03-message-sync-design.md`.
- Include status near the top when useful: `Draft`, `Proposed`, `Approved`, `Superseded`, or `Archived`.
- Link to related code, tests, and specs so readers can move from explanation to implementation quickly.
